# 开发文档

> 单文件离线 HTML 评委打分统计工具。双击即用，不装软件、不连网、数据存本机。
> 本文档面向二次开发者，说明技术结构、修改方式与踩坑记录。

---

## 一、项目结构

```
.
├── dist/
│   ├── judge-score.html     通用版（空白 20 行，任何比赛可用）

├── docs/
```

| 默认节目 | 20 行空表 | 12 个示例节目 |

## 二、技术要点（改代码前必读）

### 1. 单文件、零依赖
- 所有 CSS/JS 内联在一个 `.html` 里
- **绝对不能引入外部资源**（CDN、字体、图片链接），否则离线就废了
- 改完要检查：搜索 `src="http` / `href="http` 应该没有结果

### 2. 数据存 localStorage
- 每次改动都调 `save()`
- 打开时 `load()` 恢复
- **换电脑/清浏览器数据会丢**，所以必须靠「导出比赛设置」备份

### 3. 分数输入的核心逻辑（最容易出错的地方）

**需求**：用户敲纯数字，实时换算成小数显示。
- 10 分 / 两位：敲 `986` → 显示 `9.86`
- 100 分 / 两位：敲 `9866` → 显示 `98.66`
- 超满分：敲 `1500`（10分制）→ 按 `10.00` 计

**关键实现**：**不能用 `oninput`**，因为 `oninput` 拿到的 `inp.value` 是「已格式化的显示值 + 新敲字符」，再换算会二次换算（`9.86` → 敲 `855` → `"9.86855"` → 错）。

**正确做法**：用 `keydown` 自己维护原始输入串 `_raw`：

```js
inp._raw = '986';                    // 用户真正敲的数字
inp.value = fmtScore(9.86, 2);       // 显示换算后的值

// keydown 里手动累积
if (/^[0-9]$/.test(e.key)) {
  if (inp._freshInput) { inp._raw = ''; inp._freshInput = false; }  // 聚焦后首次输入清空
  inp._raw += e.key;
  commitRaw();
}
```

`commitRaw()` 负责：解析 → 判断超限 → 存 `row.scores[i] = _raw` → 更新显示。

**`_freshInput` 标志**：聚焦时置 `true`，首次按键时清空 `_raw`。这样重新点击格子输入是「覆盖」而不是「追加」。
注意：**已聚焦的格子再点击，`onfocus` 不再触发**，所以还要监听 `mousedown` 处理这种情况。

### 4. 表格列结构

```
[0] 序号（固定列，不可删，不可切换）
[1..N] 文本列（由 state.textOrder 控制，可下拉切换）
[N+1..N+judgeCount] 评委分数
[末尾区] 平均分 → [分数修正 → 最终成绩] → 名次
```

**「分数修正 / 最终成绩」两列由 `state.showAdjust` 控制**，勾选时才出现。
- 分数修正：可输入正负数（+0.5 / -0.3）
- 最终成绩 = 平均分 + 分数修正
- **勾选时名次按「最终成绩」排，不勾选时按「平均分」排**

**列索引是硬编码的**，改列结构时必须同步改这 8 处：
- `renderHead()` — 表头
- `renderBody()` — 表体
- `refreshStats()` — 统计刷新
- `exportExcel()` — Excel 导出
- `exportImage()` — 图片导出
- `applyPrintCols()` — 打印列隐藏
- `applyValueToCell()` — 粘贴定位
- `buildExportColumns()` — 导出列定义

**注意 `applyPrintCols()` 的列索引偏移**：有分数修正时，名次列索引要 +2。

### 5. 导出/打印自动去空行
`getUsedRows()` 过滤掉没内容的空行。导出 Excel、导出图片、打印都用它。

判断「有内容」：节目名 / 团队 / 单位 / 任一评委分 / 分数修正 有一项非空。

### 6. 去最高最低的索引同步（踩过坑）

`splice` 后索引会偏移，必须**同步维护值数组和索引数组**：

```js
let useVals = vals.slice();
let useIdx  = rawIdx.slice();   // ← 必须有这个
// 删最高
useVals.splice(hiIdx, 1);
useIdx.splice(hiIdx, 1);        // ← 同步删
// 删最低（用更新后的数组找）
const loIdx = useVals.indexOf(Math.min(...useVals));
dropped.push(useIdx[loIdx]);    // ← 用同步后的索引
```

**曾经的 bug**：只 splice 值数组，索引数组没动 → 同一个格子被记录两次。

## 三、功能清单

### 第一栏 · 功能区
| 按钮 | 作用 |
|---|---|
| ＋增加一行 / －减少一行 | 增删节目行 |
| ＋增加评委 / －减少评委 | 1-20 个评委 |
| 序号排序 | 按序号数字排，空号排最后 |
| 分数排序 | 按最终成绩（或平均分）从高到低 |
| 恢复默认设置 | 还原设置 + 补回被删的行，**不动分数** |
| 清空全部 | 全清，恢复 20 行空表 |

### 第二栏 · 规则设定
- **现场抽签顺序**（蓝色高亮框）
  - 勾选 → 确认后**清空所有序号**
  - 取消 → 确认后**重新编号**
  - 点取消 → 回滚，状态不变
- 满分：10 分 / 100 分
- 小数位：整数 / 两位 / 三位
- 奖项名额：第一名 __ 个、第二名 __ 个、第三名 __ 个
- 勾选：去掉最高最低 / 有选送单位 / 隐藏评委打分 / **分数修正-最终成绩**

### 第三栏 · 打分表格
- 标题栏在表格正上方，**可直接点击编辑**
- 列头**整格可点**切换（节目名称 ↔ 表演团队 ↔ 选送单位）
- 序号列固定，灰底，无下拉箭头
- **最高分红框、最低分蓝框**
- 平均分、最终成绩、名次实时计算
- 同分并列同名次
- **右键行**：上方插入 / 下方插入 / 删除（带确认）
- **右键单元格**：剪切 / 复制 / 粘贴 + 上方插入 / 下方插入 / 删除（带确认）

### 导入
- 粘贴节目名单，支持：制表符（Excel/Word 默认）、逗号、中文逗号、顿号、竖线、分号、2+空格
- **只取纯文本，忽略字体字号等所有格式**
- 多行多列粘贴自动拆分填充
- 优先填入空行，空行不够才追加

### 导出
- **导出列勾选**（9 项，可独立控制每一列）
- 导出 Excel（.xls，Excel/WPS 可开，带颜色）
- 导出图片（PNG，2 倍高清）
- 打印（遵循列勾选 + 自动去空行）
- **导出/导入比赛设置**（.json，打包所有配置 + 节目单）


```js
const DEFAULT_TITLE = '示例活动评分表';
```

```js
const DEFAULT_ROWS = 20;
```

### 改列名
```js
const TEXT_COLS = {
  name:  { key: 'name',  label: '节目名称' },
  actor: { key: 'actor', label: '表演团队' },   // ← 改这里
```

### 改默认设置
找 `let state = { ... }` 里的默认值。

把以下几处替换即可：
1. `STORE_KEY` → 新的键名

4. `ensureDefaultRows()` → 改成循环生成 `DEFAULT_ROWS` 行空行
5. `hasUnit` / `showAdjust` → `false`
6. `textOrder` → `['name', 'actor']`

## 六、踩过的坑

### 坑 1：分数输入二次换算
在显示值上继续输入会二次换算（`9.86` → 敲 `855` → `0.10`）。
**修法**：用 `keydown` 维护原始串 `_raw`，不读 `inp.value`。

### 坑 2：重新点击格子是追加而非覆盖
`onfocus` 只在首次聚焦触发，已聚焦时再点不触发。
**修法**：额外监听 `mousedown`，已聚焦时也重置 `_freshInput`。

### 坑 3：去最高最低索引错位
`splice` 值数组后索引数组没同步 → 同一格被删两次。
**修法**：见上文「去最高最低的索引同步」。

### 坑 4：Tab 焦点乱跳
Tab 键会跳到上方设置区。
**修法**：给表格输入框设 `tabIndex`，只在分数格之间跳。

### 坑 5：导入把表格清空重建
最初导入会 `state.rows = []` 然后重建，导致 20 行变 3 行。
**修法**：改成逐行填入现有空行，不够才追加。

### 坑 6：右键菜单点不到
`document.click` 监听器在点击菜单项时先触发关闭。
**修法**：判断 `menu.contains(e.target)`，点在菜单内部不关闭。

### 坑 7：单元格右键的菜单项变多后定位溢出
固定 `mh=130` 的高度估算不够，菜单会超出窗口底部。
**修法**：改用 `getBoundingClientRect()` 动态取实际高度。
