# 开发文档

> 单文件离线 HTML 评委打分统计工具。双击即用，不装软件、不连网、数据存本机。
> 本文档面向二次开发者，说明技术结构、修改方式与踩坑记录。

## 二、技术要点（改代码前必读）

### 1. 单文件、零依赖
- 所有 CSS/JS 内联在一个 `.html` 里
- **绝对不能引入外部资源**（CDN、字体、图片链接），否则离线就废了
- 改完要检查：搜索 `src="http` / `href="http` 应该没有结果

### 2. 数据存 localStorage
- 每次改动都调 `save()`
- 打开时 `load()` 恢复
- **换电脑/清浏览器数据会丢**，所以必须靠「导出比赛设置」备份

### 3. 分数输入的核心逻辑

**现行方案（v3.2 起）**：纯手动输入，不做任何自动换算。

- 用户输 `98.66` 就是 `98.66`
- 用户输 `85` 就是 `85`（不再自动 ÷100 变成 0.85）
- 满分可自定义（任意数字），超过满分**只标红提示，不修改值**

**实现要点**：直接监听 `input`，过滤非数字字符后解析；超满分只加 `.invalid` 类不改值。

```js
inp.addEventListener('input', () => {
  const raw = inp.value.trim();
  if (raw === '') { delete row.scores[i]; save(); refreshStats(); return; }

  const cleaned = raw.replace(/[^\d.\-]/g, '');
  if (cleaned !== raw) inp.value = cleaned;
  if (cleaned === '' || cleaned === '.' || cleaned === '-') { save(); refreshStats(); return; }

  const v = parseFloat(cleaned);
  if (isNaN(v)) { save(); refreshStats(); return; }

  // 超满分 → 标红但不改值
  if (v > state.maxScore || v < 0) {
    inp.classList.add('invalid');
    row.scores[i] = cleaned;
    save(); refreshStats();
    return;
  }

  inp.classList.remove('invalid');
  row.scores[i] = String(v);
  save(); refreshStats();
});
```

**失焦时按小数位格式化显示**（只改显示，不改存储值）：

```js
inp.addEventListener('blur', () => {
  const cur = row.scores[i];
  if (cur === undefined || cur === null || String(cur).trim() === '') {
    inp.value = '';
    return;
  }
  const n = parseFloat(String(cur));
  inp.value = isNaN(n) ? String(cur) : n.toFixed(state.decimals);
});
```

**历史坑**：早期版本用 `keydown` 维护 `_raw` 原始串实现「自动插小数点」，逻辑复杂且容易出二次换算 bug（`9.86` → 敲 `855` → `0.10`）。v3.2 已废弃该方案。

**旧数据迁移**：老版本存的可能是 `95500` 这种原始数字（应显示 95.500）。新版加载时 `migrateLegacyScores()` 检测「分数 > 满分」的情况，自动 ÷10^小数位 还原，并提示还原了几个。

### 3.1 自定义列

用户可增加任意列（如「编导」「伴奏」），存在 `state.customCols`：

```js
state.customCols = [{ key: 'custom_1', label: '编导' }, ...]
state.textOrder  = ['name', 'actor', 'unit', 'custom_1']   // 含自定义列
```

**关键函数**：
- `colLabel(key)` — 统一取列名（内置 + 自定义），所有渲染都用它而不是 `TEXT_COLS[key]`
- `addCustomCol()` — 从 `#customColInput` 读列名，生成 `custom_N` 唯一 key，push 到 textOrder
- `removeCustomCol(key)` — 删除列并从所有 row 里 `delete r[key]`
- `renderCustomColList()` — 渲染规则区的列标签（带 × 删除）

**注意**：
- `customColSeq` 是全局自增，加载时要按已有 key 重算最大值，避免重复
- 列头下拉 `openColMenu()` 要把自定义列也加进 options
- 导出勾选区 `rebuildCustomExportCols()` 动态插入自定义列的勾选项

### 3.2 撤销 / 重做

**机制**：快照栈 + 防抖。

```js
let undoStack = [];      // 历史快照（JSON 字符串）
let redoStack = [];
let lastSnapshot = '';
let snapshotTimer = null;

function save() {
  localStorage.setItem(STORE_KEY, JSON.stringify(state));
  takeSnapshot();   // 每次 save 都记快照（防抖 400ms）
}
```

**防抖**：连续输入 400ms 内合并为一步，不会一个字一步。

**上限**：保留最近 2000 步（`undoStack.shift()` 超限时丢弃最早的）。

**恢复时**：`applySnapshot()` 把 state 换掉后调 `syncAllUI()` 同步所有界面控件，并设 `isRestoring = true` 防止再次触发记录。

**坑**：初始化时会有若干 `save()` 调用，必须在 init 结尾清掉 `snapshotTimer` 并重置 `undoStack`，否则一打开就能撤销。

### 3.3 键盘快捷键

统一在 `document.addEventListener('keydown')` 里分发。

**判断顺序很重要**：
1. 先处理 `Ctrl+Z/Y`（撤销重做，任何情况下都生效）
2. 再判断 `inInput` —— 在普通输入框里只放行 `Ctrl+S`，**但要放行 Alt 组合键和 F 键**
3. 然后依次处理 Ctrl 系列、Alt 系列、F 系列

**坑**：最初 `inInput` 判断直接 `return`，导致 `Alt+I` 这类带字母的快捷键在输入框里失效。修法：

```js
const isFn = /^F\d+$/.test(e.key);
if (inInput && !inScoreCell && !e.altKey && !isFn) {
  if (ctrl && k === 's') { run(exportSetup); return; }
  return;
}
```

**Alt+方向键不可靠**：部分系统/浏览器会拦截。所以同时支持 `Alt+I` / `Alt+R` 等字母键。

### 4. 表格列结构

```
[0] 序号（固定列，不可删，不可切换）
[1..N] 文本列（由 state.textOrder 控制，可下拉切换）
[N+1..N+judgeCount] 评委分数
[末尾区] 平均分 → [分数修正 → 最终成绩] → 名次
```

**「分数修正 / 最终成绩」两列由 `state.showAdjust` 控制**，勾选时才出现。
- 分数修正：可输入正负数（+0.5 / -0.3）
- 最终成绩 = 平均分 + 分数修正
- **勾选时名次按「最终成绩」排，不勾选时按「平均分」排**

**列索引是硬编码的**，改列结构时必须同步改这 8 处：
- `renderHead()` — 表头
- `renderBody()` — 表体
- `refreshStats()` — 统计刷新
- `exportExcel()` — Excel 导出
- `exportImage()` — 图片导出
- `applyPrintCols()` — 打印列隐藏
- `applyValueToCell()` — 粘贴定位
- `buildExportColumns()` — 导出列定义

**注意 `applyPrintCols()` 的列索引偏移**：有分数修正时，名次列索引要 +2。

### 5. 导出/打印自动去空行
`getUsedRows()` 过滤掉没内容的空行。导出 Excel、导出图片、打印都用它。

判断「有内容」：节目名 / 团队 / 单位 / 任一评委分 / 分数修正 有一项非空。

### 6. 去最高最低的索引同步（踩过坑）

`splice` 后索引会偏移，必须**同步维护值数组和索引数组**：

```js
let useVals = vals.slice();
let useIdx  = rawIdx.slice();   // ← 必须有这个
// 删最高
useVals.splice(hiIdx, 1);
useIdx.splice(hiIdx, 1);        // ← 同步删
// 删最低（用更新后的数组找）
const loIdx = useVals.indexOf(Math.min(...useVals));
dropped.push(useIdx[loIdx]);    // ← 用同步后的索引
```

**曾经的 bug**：只 splice 值数组，索引数组没动 → 同一个格子被记录两次。

- **现场抽签顺序**（蓝色高亮框）

  - 点取消 → 回滚，状态不变
- 满分：**任意数字输入框**（默认 10，可填 100、200 等）
- 小数位：整数 / 一位 / 两位 / 三位（**只影响平均分和最终成绩的显示精度**）
- 奖项名额：第一名 __ 个、第二名 __ 个、第三名 __ 个
- 勾选：去掉最高最低 / 有选送单位 / 隐藏评委打分 / **分数修正-最终成绩**

### 第三栏 · 打分表格
- 标题栏在表格正上方，**可直接点击编辑**
- 列头**整格可点**切换（节目名称 ↔ 表演团队 ↔ 选送单位）
- 序号列固定，灰底，无下拉箭头
- **最高分红框、最低分蓝框**
- 平均分、最终成绩、名次实时计算
- 同分并列同名次
- **右键行**：上方插入 / 下方插入 / 删除（带确认）
- **右键单元格**：剪切 / 复制 / 粘贴 + 上方插入 / 下方插入 / 删除（带确认）
- **多选**：鼠标拖拽框选 / Ctrl+点击加选 / Shift+方向键扩展
- **标题与表头吸顶**：页面滚动时始终可见
- **分数排序按最终成绩**（含分数修正）

### 导入
- 粘贴节目名单，支持：制表符（Excel/Word 默认）、逗号、中文逗号、顿号、竖线、分号、2+空格
- **只取纯文本，忽略字体字号等所有格式**
- 多行多列粘贴自动拆分填充
- 优先填入空行，空行不够才追加

### 导出
- **导出列勾选**（9 项，可独立控制每一列）
- 导出 Excel（.xls，Excel/WPS 可开，带颜色）
- 导出图片（PNG，2 倍高清）
- 打印（遵循列勾选 + 自动去空行）
- **导出/导入比赛设置**（.json，打包所有配置 + 节目单）

## 三之二、节目计时（2026-10-24 新增，2026-10-27 改版）

计时列由规则区的「节目计时」勾选控制（`state.showTimer`，默认关闭）。

**交互流程**：

1. 单元格显示 `00:00` + 「▶ 开始」「■ 停止」
2. 点开始跑秒，按钮变「⏸ 暂停」，可反复暂停/继续
3. 点停止 → 调用 `showTimerDialog(row, seconds, td)`

**关键：确认区是页面底部的内联区块，不是弹窗**（2026-10-27 用户要求改的）。

- DOM：`<div class="timer-panel" id="timerPanel">`，位于 `.wrap` 内的**最后一个子元素**（比赛设置存档面板之后）
- 平时 `display:none`，加 `.show` 类才展开
- 内容：`第 N 行 · 节目名` + 时间输入框 + 「确认」「取消」
- 点确认 → `confirmTimer()` 写回 `row.timer` 并重渲染该格
- 点取消 → `cancelTimer()` 只收起面板，不改数据
- 输入框里 `Enter` = 确认，`Esc` = 取消

**改这块的坑**：

- 不要用 `position: fixed` 做浮层，用户明确要求「在页面最下面」
- 面板必须放在 `.wrap` 里面，否则样式和宽度对不上
- 原来那套 `.timer-modal` / `.timer-dialog` 的 CSS 从来没写过（历史遗留），旧版弹窗其实是裸 div 直接铺在页面末尾

## 六、踩过的坑

### 坑 1：分数输入二次换算
在显示值上继续输入会二次换算（`9.86` → 敲 `855` → `0.10`）。
**修法**：用 `keydown` 维护原始串 `_raw`，不读 `inp.value`。

### 坑 2：重新点击格子是追加而非覆盖
`onfocus` 只在首次聚焦触发，已聚焦时再点不触发。
**修法**：额外监听 `mousedown`，已聚焦时也重置 `_freshInput`。

### 坑 3：去最高最低索引错位
`splice` 值数组后索引数组没同步 → 同一格被删两次。
**修法**：见上文「去最高最低的索引同步」。

### 坑 4：Tab 焦点乱跳
Tab 键会跳到上方设置区。
**修法**：给表格输入框设 `tabIndex`，只在分数格之间跳。

### 坑 5：导入把表格清空重建
最初导入会 `state.rows = []` 然后重建，导致 20 行变 3 行。
**修法**：改成逐行填入现有空行，不够才追加。

### 坑 6：右键菜单点不到
`document.click` 监听器在点击菜单项时先触发关闭。
**修法**：判断 `menu.contains(e.target)`，点在菜单内部不关闭。

### 坑 7：单元格右键的菜单项变多后定位溢出
固定 `mh=130` 的高度估算不够，菜单会超出窗口底部。
**修法**：改用 `getBoundingClientRect()` 动态取实际高度。

---

### 坑 8：撤销初始状态不为空
初始化流程里有多次 `save()` 调用，导致一打开页面撤销栈就有内容。
**修法**：init 结尾清掉 `snapshotTimer`，重置 `undoStack` / `redoStack`，再设 `lastSnapshot`。

### 坑 9：Alt 组合键在输入框里失效
`inInput` 判断直接 return，把 `Alt+I` 这类带字母的组合键也拦掉了。
**修法**：放行条件加上 `!e.altKey && !isFn`。

### 坑 10：Alt+方向键被系统占用
部分 Windows / 浏览器会拦截 `Alt+↑↓`。
**修法**：同时支持字母键 `Alt+I` / `Alt+R`，说明面板里都列出来。

### 坑 11：分数排序忽略修正分
`sortByScore` 最初只按 `avg` 排，开了分数修正后排序结果不对。
**修法**：按 `state.showAdjust` 决定用 `final` 还是 `avg` 作为排序键。

### 坑 12：PowerShell 字符串替换中文不生效
用 `$c.Replace(...)` 替换含中文的长段落时经常匹配不上（换行符/编码差异）。
**修法**：改用 edit 工具精确替换，或用 Python 脚本处理。
