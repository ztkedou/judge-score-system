## 三、技术要点（改代码前必读）

### 1. 单文件、零依赖
- 所有 CSS/JS 内联在一个 `.html` 里
- **绝对不能引入外部资源**（CDN、字体、图片链接），否则离线就废了
- 改完要检查：`grep 'src="http\|href="http'` 应该没有结果

### 2. 数据存 localStorage
- 每次改动都调 `save()`
- 打开时 `load()` 恢复
- **换电脑/清浏览器数据会丢**，所以必须靠「导出比赛设置」备份

### 3. 分数输入的核心逻辑
用户输入**纯数字**，按小数位在末尾插入小数点：

```js
function parseScore(raw, maxScore, decimals) {
  // 928 + 10分/两位 → 9.28
  // 1000 + 10分/两位 → 10.00
  // 9850 + 100分/两位 → 98.50
  // 如果用户自己打了小数点，直接 parseFloat
  if (s.includes('.')) return parseFloat(s);
  return parseInt(s) / Math.pow(10, decimals);
}
```

### 4. 表格列结构（关键）
```
[0] 序号（固定列，不可删，不可切换）
[1..N] 文本列（由 state.textOrder 控制，可下拉切换）
[N+1..N+judgeCount] 评委分数
[末尾-1] 平均分
[末尾] 名次
```

**列索引是硬编码的**，改列结构时必须同步改：
- `renderHead()` — 表头
- `renderBody()` — 表体
- `refreshStats()` — 统计刷新
- `exportExcel()` — Excel 导出
- `exportImage()` — 图片导出
- `applyPrintCols()` — 打印列隐藏
- `applyValueToCell()` — 粘贴定位

### 5. 去最高最低的索引同步（踩过坑）
`splice` 后索引会偏移，必须**同步维护值数组和索引数组**：

```js
let useVals = vals.slice();
let useIdx  = rawIdx.slice();   // ← 必须有这个
// 删最高
useVals.splice(hiIdx, 1);
useIdx.splice(hiIdx, 1);        // ← 同步删
// 删最低（用更新后的数组找）
const loIdx = useVals.indexOf(Math.min(...useVals));
dropped.push(useIdx[loIdx]);    // ← 用同步后的索引
```

**曾经的 bug**：只 splice 值数组，索引数组没动 → 同一个格子被记录两次。

## 四、功能清单

### 第一栏 · 功能区
| 按钮 | 作用 |
|---|---|
| ＋增加一行 / －减少一行 | 增删节目行 |
| ＋增加评委 / －减少评委 | 1-20 个评委 |
| 序号排序 | 按序号数字排，空号排最后 |
| 分数排序 | 按平均分从高到低 |
| 恢复默认设置 | 还原设置 + 补回被删的行，**不动分数** |
| 清空全部 | 全清，恢复 20 行空表 |

### 第二栏 · 规则设定
- **现场抽签顺序**（蓝色高亮框，最显眼）
  - 勾选 → 确认后**清空所有序号**
  - 取消 → 确认后**重新编号**
  - 点取消 → 回滚，状态不变
- 满分：10 分 / 100 分
- 小数位：整数 / 两位 / 三位
- 奖项名额：第一名 __ 个、第二名 __ 个、第三名 __ 个
- 勾选：去掉最高最低 / 有选送单位 / 隐藏评委打分

### 第三栏 · 打分表格
- 标题栏在表格正上方，点击可跳到输入框
- 列头**整格可点**切换（节目名称 ↔ 表演团队 ↔ 选送单位）
- 序号列固定，灰底，无下拉箭头
- **最高分红框、最低分蓝框**
- 平均分、名次实时计算
- 同分并列同名次
- **右键行**：上方插入 / 下方插入 / 删除（带确认）
- **右键单元格**：剪切 / 复制 / 粘贴

### 导入
- 粘贴节目名单，支持：制表符（Excel/Word 默认）、逗号、中文逗号、顿号、竖线、分号、2+空格
- **只取纯文本，忽略字体字号等所有格式**
- 多行多列粘贴自动拆分填充
- 优先填入空行，空行不够才追加

### 导出
- **导出列勾选**（7 项，默认勾序号/节目名称/表演团队/平均分/名次）
- 导出 Excel（.xls，Excel/WPS 可开，带颜色）
- 导出图片（PNG，2 倍高清）
- 打印（遵循列勾选）
- **导出/导入比赛设置**（.json，打包所有配置 + 节目单）

## 七、踩过的坑

### 坑 1：去最高最低索引错位
`splice` 值数组后，索引数组没同步 → 同一格被删两次。
**修法**：见上文「去最高最低的索引同步」。

### 坑 2：评分项名被误改
最初评分项名是直接可编辑的 input，用 Tab 填分数时光标跳上去改坏了名字。
**修法**：改成默认显示文字，点 ✎ 才进入编辑。

### 坑 3：Tab 焦点乱跳
Tab 键会跳到上方设置区。
**修法**：给表格输入框设 `tabIndex`，只在分数格之间跳。

### 坑 4：导入把表格清空重建
最初导入会 `state.rows = []` 然后重建，导致 20 行变 3 行。
**修法**：改成逐行填入现有空行，不够才追加。

### 坑 5：右键菜单点不到
`document.click` 监听器在点击菜单项时先触发关闭。
**修法**：判断 `menu.contains(e.target)`，点在菜单内部不关闭。

### 坑 6：中文 zip 名/中文文件名
如果以后要打包分享，中文文件名在某些环境会乱码。**建议用英文名**。
