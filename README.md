# 评委打分系统 · Judge Score System

> 一个**单文件、完全离线、双击即用**的评委打分统计工具。
> 不装软件、不连网络、数据存在本机浏览器里。

## 为什么做这个

用 Excel 统分，有两个绕不开的麻烦：

1. **容易输错** —— 分数敲错一位，平均分跟着错，还不容易发现
2. **依赖 Office** —— 现场那台电脑不一定装了 Excel，或者版本不对、弹激活

这个工具就是为解决这两点：**一个 HTML 文件，双击打开，填数字，自动出结果。**

## 功能

### 分数输入：只敲数字，自动换算

设定满分和小数位后，直接敲数字，系统自动插入小数点：

| 设定 | 你敲 | 显示为 |
|---|---|---|
| 10 分 / 两位 | `928` | **9.28** |
| 10 分 / 两位 | `1000` | **10.00** |
| 100 分 / 两位 | `9850` | **98.50** |
| 10 分 / 三位 | `9285` | **9.285** |

> 想自己打小数点也可以，`9.5` 就是 9.5。

### 实时统计

- **最高分红色框**、**最低分蓝色框**，一眼看出谁打高打低
- **平均分、名次实时计算**，边填边更新
- **同分自动并列**（两个都 8.00 分，名次都是 3）

### 评分规则可配

- 满分：**10 分 / 100 分**
- 小数位：**整数 / 两位 / 三位**
- 评委人数：**1-20 人**，随时增减
- **去掉一个最高分和一个最低分**（可选）
- 奖项名额：第一名 __ 个、第二名 __ 个、第三名 __ 个
- 隐藏评委打分（投屏时可隐藏具体分数）

### 现场抽签顺序

比赛现场常要抽签决定出场顺序。勾选「现场抽签顺序」后：

- **表格里所有序号自动清空**，等现场抽签后手填
- 填完点「序号排序」，自动按抽签号排好
- 切换时会弹确认框，点错也能回滚

### 导入：从 Excel / Word 直接粘贴

支持从 **Excel 复制单元格区域**、**Word 表格**直接粘进来，也可以手打。

**自动识别这些分隔符**：

| 分隔符 | 常见来源 |
|---|---|
| 制表符 `Tab` | Excel / Word 复制默认 |
| 逗号 `,`、中文逗号 `，` | 手打 |
| 顿号 `、` | 手打 |
| 竖线 `\|` | 网页表格 |
| 分号 `;`、`；` | 手打 |
| 两个以上连续空格 | 文本对齐 |

**只取纯文本内容** —— 字体、字号、颜色、加粗这些格式全部忽略，只把文字填进表格。

### 导出：想要哪列导哪列

导出前可勾选包含哪些列，默认勾选：**序号、节目名称、演出人员、平均分、名次**。

三种导出方式：

- **导出 Excel**（`.xls`）—— Excel / WPS 直接打开，保留最高最低的颜色标记
- **导出图片**（`.png`）—— 2 倍高清，适合发群、做公示
- **打印** —— 自动隐藏按钮区，只打表格

### 比赛设置存档

**赛前配好，现场直接用。**

点「导出比赛设置」会打包成一个 `.json` 文件，包含：

- 活动标题
- 全部评分规则（满分、小数位、评委数、奖项、勾选项）
- 完整节目单（含已填的分数）

**比赛现场**：打开网页 → 「导入比赛设置」→ 选那个 json → **直接开始打分**，不用再配节目单。

## 操作细节

### 右键菜单

- **在行上右键**：上方插入一行 / 下方插入一行 / 删除这一行
- **在单元格上右键**：剪切 / 复制 / 粘贴

### 键盘操作

- `Tab` —— 跳到下一个格子（只在分数格之间跳）
- `Enter` —— 跳到下一行同列
- `Ctrl+Enter` —— 在导入框里直接执行导入
- `Esc` —— 关闭右键菜单

### 列头切换

点击「节目名称」「演出人员」「选送单位」这些列头**任意位置**，可以把它们互相调换位置。比如把第一列从「节目名称」换成「选送单位」。

### 恢复默认设置

点「恢复默认设置」会：
- 还原所有评分规则到默认值
- **把被删掉的节目行补回来**
- **保留所有已打的分数**

## 数据安全

### 数据存在哪

存在**这台电脑的浏览器**里（localStorage）。关闭页面、断网、重启电脑都不会丢。

### 什么时候会丢

- 换电脑（不同浏览器的存储是独立的）
- 清理浏览器数据 / 用无痕模式
- 更换浏览器

### 怎么备份

**赛前务必点一次「导出比赛设置」**，存一份 `.json` 到 U 盘或网盘。这个文件包含节目单和所有配置，下次导入就能完整恢复。

## 技术实现

- **纯原生** HTML + CSS + JavaScript，无框架、无构建、无依赖
- 单文件约 70-85 KB
- 数据持久化：`localStorage`
- 导出 Excel：生成 HTML 表格格式的 `.xls`（Excel/WPS 都能识别）
- 导出图片：`Canvas` 手绘，2 倍高清
- 测试：Playwright 无头浏览器，51 项覆盖

**没有任何网络请求**，断网也能完整使用。

## 常见问题

**Q：打开是空白 / 显示代码？**
右键文件 → 打开方式 → 选择 Chrome 或 Edge。

**Q：数据突然不见了？**
可能是清理了浏览器数据。用之前导出的「比赛设置」文件恢复。

**Q：能多人同时打分吗？**
不能。这是单机工具，一个评委一台设备，或者一台电脑轮流录入。如果需要多人实时协作，需要另外的服务器方案。

**Q：分数输错了怎么改？**
直接点那个格子重新输入即可，平均分会自动重算。

**Q：能导出给 Excel 做进一步处理吗？**
能。点「导出 Excel」，得到一个 `.xls` 文件，Excel/WPS 都能打开继续编辑。
